# StandBy Desk Clock

> A lightweight, highly customizable web application that transforms your smartphone or tablet into an elegant landscape nightstand display inspired by iOS StandBy mode.

## Features
- **Multiple Clock Styles:** Switch between Digital, Analog, Flip Clock, and Word Clock modes.
- **Themes & Colors:** Includes iOS StandBy, Night Mode (Red tint), Neon, Ocean, Minimal, and custom colors.
- **Always-On Display:** Uses Web Wake Lock API to keep the screen active.
- **Widgets:** Shows date, weekday, battery status, and optional seconds.
